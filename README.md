This project is to solve basic mazes . The whole idea is that Rover produces clones then those clones search 4 step ahead . Then they will tell the rover if there is a dead end 3 steps(or less) ahead of him .
If there is an dead end ahead of the rover and there is no way out except turning back then my backtrack function comes in and solves the problem .
 I used no extra library . I used basic Python tools . And whole idea was to create this solver with basic Pyhton.
